Stellar · South Africa

A research tool built for the languages you actually work in.

Stellar is a free, offline-first desktop environment for humanities scholars. No cloud. No AI. No subscription. South African language support is in progress — and we need people who know the languages to help get it right.

Why South Africa

One of the world's most linguistically complex research contexts.

South Africa recognises 12 official languages, has a long tradition of humanities and archival scholarship, and a research community that operates across multiple language contexts simultaneously. Within the Global South, it stands apart — not just for linguistic diversity, but for the depth of its academic infrastructure.

Most research tools are built for English. A few support one or two European languages. Stellar is designed to go further — and South Africa is a meaningful place to start.

The Tool

What Stellar does.

Stellar is a single desktop app for humanities researchers. Everything in one place, on your own machine.

Now Citation manager — store, tag, and search papers and books.
Now Markdown editor with bidirectional WikiLinks — connect ideas as you write.
Now Qualitative coding tool — code text data, build themes, without expensive commercial software.
Now Citation network graph — visualize how your sources connect.
Planned NLP-assisted qualitative analysis — using language resources to process multilingual research material.

That last item is where South African language resources matter most. If isiZulu or isiXhosa NLP data can be integrated into Stellar's analysis layer, the tool stops being a translated English app and starts being something that actually understands the material researchers work with. That's useful not just in South Africa, but across the African continent — for any researcher working in languages that current tools ignore.

Localization here isn't cosmetic. It's infrastructure.

What you can do with Stellar

Concretely, for a South African humanities researcher.

Stellar is a desktop research workbench. Everything below runs on your machine, without internet, and without an account. Below are some of the ways the tool fits into research workflows common in South African humanities and social science departments.

Postgraduate · Thesis writing

From a pile of PDFs to a finished chapter.

Import the papers you have downloaded — by PDF, DOI, URL, or manual entry. Highlight key passages in four colours (importance, methodology, your argument, questions). Turn highlights into notes. Connect notes with [[WikiLinks]]. Switch to Draft Mode to write your chapter with inline citations in APA, MLA, or Chicago.

PDF Reader Notes + WikiLinks Draft Mode Citation styles
Historian · Archival research

Tracking primary sources alongside secondary literature.

Add archival documents — photographed letters, oral history transcripts, government records — the same way you add published papers. Use the Source Criticism tab to evaluate author, date, authenticity, bias, and reliability. Use the Timeline tab to organise events chronologically. Use the Actor Map to visualise relationships between people, institutions, and organisations.

Source Criticism Timeline Actor Map Process Tracing
Sociologist · Qualitative coding

Coding interview transcripts and policy documents.

Build a hierarchical codebook. Apply codes to text passages across multiple documents. Use the Coding Matrix to see code-by-document distributions. Run ICR (Cohen's Kappa) when you work with co-coders. Use Framing Analysis for media or policy corpora. Generate an analysis report at the end — no separate commercial coding tool needed.

Codebook Coding Matrix ICR Framing Analysis
Political scientist · Comparative work

Comparing cases across countries, parties, or periods.

Use Comparative Design (MSSD / MDSD) to lay out cases against variables. Use Process Tracing to test causal hypotheses against evidence. Build a citation network across your literature to find clusters and gaps. Import CSV data into Data Studio for descriptive statistics, frequency tables, correlations, and regression. Export your results as PDF, DOCX, or a static HTML site.

Comparative Design Citation Network Data Studio Export
Linguist · Multilingual sources

Working with sources in more than one language.

Stellar's full-text search (FTS5) works across mixed-language libraries — English alongside Afrikaans, and once localization progresses, isiZulu, isiXhosa, Setswana, Sesotho, and Sepedi. Tag sources by language. Run token frequency and TF-IDF analyses in Data Studio. The interface itself adapts: switch the app language at any time from Settings.

FTS5 search Multilingual UI Text analysis

A typical 30-minute first session

  1. Open Stellar, choose your language and storage folder (default ~/Stellar is fine).
  2. Drag one PDF into the Library. Stellar reads the metadata automatically.
  3. Open the PDF, highlight one passage in yellow, add a comment.
  4. Create a note from that highlight. Write what you'd want to remember about it.
  5. Type [[ and link the note to another concept or paper.
  6. Open the Knowledge Graph from the sidebar. You should see your first node and link.
  7. That's the loop. The rest of Stellar — qualitative coding, citation network, Data Studio, export — builds on this same pattern.
