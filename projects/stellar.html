PROJECT 02 — STELLAR

読む。考える。
書く。つなげる。

CORE FEATURES

一つの場所で。

01
文献ライブラリ + PDFリーダー
論文を集めて、読んで、ハイライトする。本棚と読書ノートを、一体で。
DOI、URL、PDFから書誌情報を自動取得
4色のハイライトでマーカーを引ける
ハイライトをそのままノートに変換
02
ノート + WikiLink
Markdownで書く。[[ノート名]] で別のノートに繋ぐ。@cite{論文ID} で引用を挿入。
Markdown、双方向リンク、自動保存
フォーカスモードで集中できる
PDF / DOCX / 静的HTML として出力
03
ナレッジグラフ
論文とノートのつながりを、ネットワーク図として可視化。300ノードを超えても動きます。
フォース指向の動的グラフ
タグ・種類でフィルタ可能
ミニマップで全体を俯瞰
And More
[ 06 ADDITIONAL FEATURES ]
04
草稿モード
3カラムレイアウト。アウトライン、エディタ、引用パネル。レポートや論文を書くときに。
05
引用スタイル
APA 7 / MLA 9 / Chicago 17 / 一橋方式。Word出力にも対応。
06
グローバル検索
SQLite FTS5 で、論文・ノート・ハイライトを横断検索。Ctrl+K で開く。
07
質的分析(QDA)
コードブック、マトリクス、ICR、タイムライン、アクターマップ、フレーミング分析など11ツール。
08
量的分析(Data Studio)
CSV取込、記述統計、相関、t検定、回帰、テキスト共起ネットワーク、グラフ書出し。
09
研究パッケージ
.stellar ファイルとして書出し・読込。研究グループでの共有に。
